# UX strategy

Base it on the project's brief (`docs/brief/brief.md`). If there is no
brief, say so and offer `/brief` first.

Use `templates/strategy.md` from dani-studio (locally: `~/.claude/dani-templates/strategy.md`) as the structure.

## Steps

1. Restate the core problem in one sentence.
2. Define positioning: who it's for, what makes it different, the proof.
3. Set 3–5 strategic priorities, each tied to a business goal from the brief.
4. State the trade-offs: what we explicitly won't do now and why.
5. Outline the experience principles (3–5) that will guide design choices.
6. Propose the research needed to validate the riskiest assumptions.
7. Save to `docs/strategy/strategy.md`; end with a ranked next-steps list.
