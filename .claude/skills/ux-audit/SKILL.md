# UX audit

## Steps

1. Confirm the goal of the audit and the key user tasks (from the brief if
   one exists).
2. Review at **phone width first**, then desktop. If a browser tool is
   available, take screenshots; otherwise work from fetched page content and
   say what couldn't be checked.
3. Assess each area:
   - **First impression**: is it clear what this is and who it's for within 5 seconds?
   - **Navigation & IA**: can users find the key tasks?
   - **Content**: clarity, hierarchy, tone, calls to action
   - **Conversion**: path to the primary action, friction, trust signals
   - **Accessibility** (WCAG 2.2 AA): contrast, headings, alt text, focus, forms, tap targets
   - **Visual consistency**: type, colour, spacing, components
   - **Performance & SEO basics**: load feel, titles, meta descriptions
4. For each finding record: *where*, *what*, *evidence type*
   (observed / data / heuristic), *severity* (high / medium / low), *fix*.
5. Save to `docs/research/ux-audit.md`. Lead with a 5-line summary and the
   top 5 fixes ranked by impact vs effort.
