# Competitor review

## Steps

1. Agree the list: 3–6 direct competitors plus 1–2 "best in class"
   examples from outside the sector. Ask Dani if unsure.
2. For each, capture: positioning line, audience, primary CTA, navigation
   structure, standout patterns, weaknesses, pricing visibility, trust signals.
3. Build a comparison table across the same criteria.
4. Pull out: patterns users will expect (table stakes), gaps we can own
   (opportunities), and things to avoid.
5. Save to `docs/research/competitor-review.md` with a short summary of
   implications for the strategy.

Label anything not directly observed as an assumption.
