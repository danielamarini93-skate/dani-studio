# Playground

Small projects, quick tries and little things that don't need their own repo.

## How it works

- **One folder per thing**, named `YYYY-MM-short-name`
  (e.g. `2026-11-logo-sketches/`).
- Inside, keep it loose: files, notes, a short `README.md` saying what it is
  and where it got to.
- **Ideas not started yet** go in [`ideas.md`](ideas.md). When you start
  one, move it into its own folder.

## When to move something out

Give it its own repo when it:

- gets a client or a real deadline,
- needs its own design system, or
- needs the full process (`/design-thinking` → `/design-build` → `/design-review`).

Then delete the folder here (ask first) or leave a one-line pointer to the new repo.
