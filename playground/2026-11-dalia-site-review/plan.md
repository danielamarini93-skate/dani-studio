# Review plan — dayfulplaytherapy.co.uk

**Scope:** all 5 pages in the sitemap: Home, About, School, How it works, Contact.
**Goals judged against:** (1) enquiries, (2) being found online, mainly local search.
**No brief on file**, so "brief fit" is judged against these two goals.
**Depth:** thorough. **Audience:** Dani only.
**Mobile first:** every page checked at 390px wide, then at desktop width.

## Checks

### 1. Brief & goal fit
- [x] Is the main action ("get in touch") clear on every page, and above the fold on mobile?
- [x] Enquiry path: how many taps from landing to sending an enquiry? Does the contact form work and stay short?
- [x] Content for parents (and schools): who it's for, what play therapy is, how it works, where, cost/TBC, credentials, trust signals.

### 2. Visual & design system
- [x] Hierarchy, spacing, alignment and type consistency across pages (screenshots at both widths).
- [x] Copy quality, plain language and UK spelling; repetition or filler (per Dani's taste notes).
- [x] `unslop` pass for AI-looking or template tells.
- [x] `web-design-guidelines` interface rules.

### 3. Accessibility (WCAG 2.2 AA)
- [x] `accessibility-scan` on all 5 pages (automated).
- [x] `accessibility-inspect` on Home and Contact: keyboard, focus, screen-reader names, form errors, zoom/reflow.

### 4. SEO & performance
- [x] `seo-audit` across the site: titles, descriptions, headings, indexing, sitemap, schema, images/alt, internal links.
- [x] `seo-local`: location signals, LocalBusiness schema, Google Business Profile (whether one is findable), NAP consistency.
- [x] `seo-geo`: how well AI search tools could cite the site.
- [x] Performance: Lighthouse / Core Web Vitals on mobile, Home + Contact.
- [ ] OpenSEO keyword/ranking data: skipped, as agreed.

## Output
- `review.md` in this folder: a 5-line summary, pass / needs work for each check, and every fix ranked by impact vs effort, each tagged **doable in Wix** or **Wix limit**.
- Every finding labelled *observed / data / recommendation*.
- Screenshots kept in `screens/`.
- Ends with a list of what was **not** checked and why.
